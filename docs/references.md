# 参考資料

## 現行ダイナモの元になった記事

**AkiRacing「加速度型シャーシダイナモの製作（エコラン，小排気量バイク用）」**（2017-06-18）
[Wayback Machine のアーカイブ](https://web.archive.org/web/20190919205656/http://akiracing.com/2017/06/18/chassis_dynamometer/)（元のサイトは閉鎖）

要点（設計に関わる部分の要約）。自チームの現行ダイナモはこの記事を参考にしたが、ローラはミノウラの自転車用ローラ台のローラ（φ105）、増速はチェーン 40:19 で、記事の部品とは異なる:

- 製作費 5 万円。フライホイールの慣性を走行負荷として使う加速度型（T = Iα）。一定速度では負荷がかからないが、エコランは全開で加速するので、大会と同じ負荷を与えられる。
- 渦電流ブレーキやモーターで負荷を与える型は、一定速度でも負荷を与えられ、負荷をすぐ変えられるが高価。
- フライホイールの大きさ: I = 車体総重量 × ローラ半径²。慣性は増速比の 2 乗で効くので、増速してフライホイールを小さくし、持ち運びやすくした。
- フレーム: アルミパイプ 20×40 t2.0 の溶接。FEM で安全率 5.7。
- 主な部品（ミスミの寸法指定品）:

| 部品 | 型番 |
| --- | --- |
| ローラ | ROLJT80-25-200-E75-F75-P5-S5（φ80） |
| シャフト | SSFGKRRA25-350-…（2 本） |
| チェーン・スプロケット | CHE25-U、K25B75、SP25B25-N-12（75T/25T = 3 倍） |
| 軸受 | C-PDR25 |
| その他 | キー KESF8、セットカラー SSCSW25-12、キャスター 420R-R50 |

- フライホイールはワイヤー放電加工で切り出し。
- 試験は 2 人で行う。加速・ブレーキの際は車体の移動に注意。走行パターンと同じ速度で加速の開始・終了をすると、大会と同じような燃費が出る。
