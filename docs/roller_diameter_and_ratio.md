# ローラ径と増速比の比較（φ105 流用か φ250 か）

以前の案（ローラ φ250・3 倍増速）と、現行のローラ φ105 を流用して増速比だけを見直す案を比べる。φ250 のローラは外注加工が要るが、増速比はプーリーやスプロケットの交換で安く変えられる。

## 結論

- **トルクセンサ・モーター・フライホイールの条件は、増速比をローラ径に比例させればまったく同じになる**。軸のトルクと回転数の積は T·ω = F·v で、ローラ径によらないため。φ250 × 3 倍は、φ105 では 1.26 倍に当たる。
- むしろ以前の **φ250 × 3 倍のままでは TP-20KCE が使えない**（2 N·m ＝ ローラ表面 48 N しか測れない）。φ250 で 95 N を測るには 5.94 倍に増速する必要がある。
- **損失（30 km/h で 44 N）の大半は、ローラ径ではなく駆動系**と見込まれる。タイヤとローラの接触による損失は数 N 以下で、φ250 にしても減るのは 1 N 程度。チェーン 2 段・軸受のシール・フライホイールの風損の方が大きい。
- **φ105 を流用し、増速比を 2.3〜2.5 倍に見直すのを推奨する**。ローラから 1 本の軸へ歯付きベルト 1 段で増速し、その軸にフライホイールとモーターを載せて、チェーン 2 段をやめる。
- φ105 で残る制約は、①ローラが 80 km/h で 4,040 rpm になる（ミノウラのローラの振れ・軸受を確かめる）、②タイヤの接触が φ250 より厳しい（曲率の係数 2.4 対 1.73、発熱）、③台上と路面の転がり半径の差（−0.8%）を較正する、の 3 つ。

- **φ250 × 5.94 と φ105 × 2.5 は、軸の回転数・トルク・フライホイールが同じ**になる（上の表の 2 行目と 5 行目）。
- フライホイールに蓄える運動エネルギー（80 km/h で約 26 kJ）も構成によらず同じ。ガードの要件は変わらない。
- タイヤ接触の係数は、ドラム上の転がり抵抗が平坦路の √(1 + r_タイヤ / R_ローラ) 倍になるという近似で、タイヤ半径 0.25 m と仮定した値（平坦路 = 1）。

## 2. ローラ径で変わること

| 項目 | φ105 | φ250 | 影響の大きさ |
| --- | --- | --- | --- |
| タイヤ接触の損失 | 平坦路の約 2.4 倍、接触 2 か所 | 約 1.7 倍、接触 1 か所 | 車両全体の転がり抵抗が実走で約 1.1 N なので、駆動輪 1 本の分は 2.4 倍・2 か所でも数 N 以下。**φ250 にして減るのは 1 N 程度**と見込む |
| タイヤの発熱 | 接触が短く変形が大きい | 小さい | 8 周（30 分）の通しでタイヤ温度が上がり、損失が変わる。試験の前後で損失を測る（R-V-03） |
| ローラの回転数 | 80 km/h で 4,040 rpm | 1,700 rpm | **φ105 の主な制約**。ミノウラのローラは自転車用で、この回転数での振れ・軸受を確かめる必要がある |
| ローラ軸のベルト・チェーン速度 | 40T で 17〜34 m/s（チェーンのピッチ 6.35〜12.7 mm） | 約 2.4 分の 1 | ローラチェーンには速すぎる。歯付きベルト（HTD 5M・40T で 13.5 m/s）にする |
| 転がり半径の差 | 台上 119.3 対 実走 120.3 rpm/(km/h)（−0.8%） | 小さくなる見込み | そのままだと 1 周で約 18 m ずれる（R-V-08 は ±10 m）。どちらでも較正（R-V-02）で合わせる |
| エンコーダーの分解能 | 3,032 パルス/m | 1,273 パルス/m | **φ105 が有利** |
| 駆動輪の保持 | 2 本のローラの間に収まる | 1 本の頂点に乗るので拘束が要る | φ105 が有利 |
| 費用 | 流用（0 円） | 外注加工 4〜10 万円＋軸受 | φ105 が有利 |

## 3. 損失の内訳の見込み

LOG0650 の惰行で 30 km/h 44 N（15.6 + 1.5v + 0.23v²、v は m/s）。粗い見積もり:

| 要因 | 30 km/h の見込み | 根拠 |
| --- | --- | --- |
| タイヤとローラの接触 | 数 N 以下 | 実走の転がり抵抗（車両全体で 1.1 N）× 曲率の係数 2.4 × 接触 2 か所 |
| 軸受の接触シール | 約 6 N | 1 個 0.03 N·m と仮定。ローラ軸 2 個＋フリーローラ 2 個＋2.105 倍の軸 4 個 |
| フライホイールの風損 | 約 2 N（40 km/h で 3.6 N、80 km/h で 12.6 N） | φ300 円板の乱流の式（両面） |
| チェーン 2 段 | 残りの多く | 定数項 15.6 N の多くを占めると見込む |

これは推定で、測っていない。**車両を載せずにフライホイールを回して惰行させる試験**で、タイヤ以外の損失（チェーン・軸受・風損）を分けて測れる（R-V-03）。

## 4. 推奨する変更（φ105 を流用）

```
 現行:  ローラ 40T ─チェーン 1─ 中間軸 19T＋42T ─チェーン 2─ フライホイール軸 42T（＋モーターを同軸）
 変更:  ローラ プーリー ─歯付きベルト 1 段（2.3〜2.5 倍）─ 1 本の軸＝フライホイール＋モーター（反力型で TP-20KCE）
```

| 項目 | 内容 |
| --- | --- |
| 増速比 | **2.3〜2.5 倍**。モーターの最高回転数で決める（2.3 倍で 9,300 rpm、2.5 倍で 10,100 rpm。雨の 55 km/h までなら 6,400〜6,900 rpm） |
| 駆動 | 歯付きベルト 1 段（例: HTD 5M、ローラ側 40T・軸側 16〜17T）。チェーン 2 段と中間軸（軸受 2 個）をなくす |
| フライホイール | 慣性を 0.065 → 0.046〜0.055 kg·m² に減らす（現行のまま 2.5 倍にすると回転マスが 148 kg 相当になる）。外周を削って小径にすると風損も減る。モーターの回転子の慣性も含めて合わせる（R-V-04） |
| 軸受 | 非接触シールかシールドの玉軸受にする（UC 形の接触シールをやめる） |
| ローラ | φ105 を流用。75〜80 km/h まで回して振れを確かめ、だめならローラの交換（同径の金属ローラ）か、コースの再現の上限速度を下げる |

**φ250 にするのは、φ105 で 80 km/h まで回せないとわかったときと、タイヤの発熱で損失が試験中に大きく変わるとわかったときに限る。**
